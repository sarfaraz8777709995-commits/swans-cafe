# Swans Cafe Website

A responsive static website starter inspired by the reference layout and recoloured in blush pink, rose and cream for Swans Cafe.

## Files
- `index.html` — page structure and sample content
- `styles.css` — responsive styling and colour theme
- `script.js` — mobile navigation, menu filters and demo reservation form

## Run locally
Open `index.html` in a browser. For a local development server, run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Before publishing
1. Replace sample menu names and `₹—` prices with the real Swans Cafe menu.
2. Add the cafe's real address, opening hours, phone and email.
3. Connect the reservation form to WhatsApp, email, or a booking backend. It is currently a front-end demo only.
4. Replace stock photo URLs with Swans Cafe's own approved photos.
5. Add the final logo if available.

Images and Google Fonts load from external services, so an internet connection is needed for those assets.
